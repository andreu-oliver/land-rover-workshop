Clutch Master Cylinder - LHD (33.20.01)

Removal

  1. Remove the 2 stop lamp switches.
    For additional information, refer to Stoplamp Switch (70.35.42)
  2. Remove 3 screws securing closing panel to lower 'A' pillar.
    1. Release closing panel sufficient to gain access to clutch and brake pedal bracket bolts.
    Closing panel screws (E107374)
  3. Remove clutch pedal rubber.
    4. Clutch pedal rubber removal (E105831)
  4. Remove 12 bolts securing clutch and brake pedal brackets to body.
    5. Clutch and brake pedal brackets bolts (E107375)
  5. NOTE: Some variation in the illustration may occur, but the essential information is always correct.

Disconnect multiplug from clutch pedal sensor.

  1. Disconnect multiplug and harness clip from pedal bracket.
Clutch pedal sensor multiplug (E105835)
  1. NOTE: Some variation in the illustration may occur, but the essential information is always correct.

    Position cloth to collect fluid spillage.

    1. Loosen pipe union, release pipe and plug pipe and master cylinder.
    2. Move brake master cylinder assembly aside and lift out clutch master cylinder assembly.
    Fluid spillage collection and master cylinder removal (E105836)
  2. Remove 6 screws, remove pedal box top cover and discard gasket.
    3. Pedal box top cover screws (E107373)
  3. Remove nut securing push rod to clutch pedal trunnion.
Push rod nut removal (E105832)
  1. Remove clutch pedal sensor and pipe union from master cylinder and discard sealing washers.
    1. Remove 2 bolts and remove clutch master cylinder from pedal bracket.
    Clutch pedal sensor and pipe union removal (E105834)

Installation

  1. Check seal on pedal box at points indicated and seal with RTV if necessary.
    2. Pedal box seal check (E107376)
  2. Install new lock nuts to master cylinder.
New lock nuts installation (E107377)
  1. Clean sensor and pipe union.
    1. Install new gasket.
    2. Position master cylinder to pedal bracket and align push rod to pedal trunnion.
    3. Install bolts and nuts and secure master cylinder to pedal bracket.
    4. Install clutch pedal sensor and pipe to master cylinder using new sealing washers.
    Sensor and pipe union installation (E105834)
  2. Install clutch master cylinder and mounting bracket.
    1. Clean clutch pipe union.
    2. Align pipe and tighten union.
    Clutch master cylinder and mounting bracket installation (E105836)
  3. Connect multiplug to clutch pedal sensor.
Clutch pedal sensor multiplug connection (E105835)
  1. Tighten bolts securing clutch pedal and brake pedal brackets to body.
    2. Clutch pedal and brake pedal brackets bolts tightening (E107375)
  2. Install clutch pedal rubber.
    3. Clutch pedal rubber installation (E105831)
  3. Position closing panel and tighten screws to lower 'A' pillar.
    4. Closing panel positioning (E107374)
  4. Install the 2 stoplamp switches.
    For additional information, refer to Stoplamp Switch (70.35.42)
  1. Install and lightly tighten nut securing push rod to clutch pedal trunnion.
    2. Push rod nut tightening (E105832)
  2. Check distance from lower edge of clutch pedal to down position. Correct measurement is 135 mm (5.31 in).
    3. Clutch pedal travel measurement (E107371)
  3. Adjust master cylinder push rod lock nuts and nylon nut untill 135mm (5.31 in) is achieved.
    1. Tighten lock nuts.
    2. Tighten nylon nut securing push rod to clutch pedal trunnion.
    Master cylinder push rod adjustment (E107372)
  1. Check pedal travel is to correct measurement.
    2. Pedal travel measurement (E107371)
  2. Install a new gasket to cover plate and secure with the 6 screws.
    1. Connect multiplug and harness clip to pedal bracket.
    Gasket and cover plate installation (E107373)
  3. Bleed clutch hydraulic system.
    For additional information, refer to Clutch System Bleeding

Clutch Master Cylinder - RHD (33.20.01)

Removal

  1. Remove the 2 stop lamp switches.
    For additional information, refer to Stoplamp Switch (70.35.42)
  2. Remove 3 screws securing closing panel to lower 'A' pillar.
    3. Closing panel screws (E105829)
  3. Remove clutch pedal rubber.
    4. Clutch pedal rubber removal (E105831)
  4. Release closing panel sufficient to gain access to clutch bracket bolts.
    1. Remove 6 bolts securing clutch pedal bracket to body.
    Clutch bracket bolts removal (E105828)
  5. Disconnect the expansion tank return hose and plug connections.
    1. Remove bolt and tie aside expansion tank.
Expansion tank return hose (E105827)
  1. Disconnect multiplug clutch pedal sensor.
    2. Clutch pedal sensor multiplug (E105835)
  2. Remove and tie aside the multiplug mounting bracket.
    1. Remove and tie aside the brake pipe mounting bracket.
    Multiplug mounting bracket removal (E105830)
  3. Loosen pipe union, release pipe and plug pipe and master cylinder.
    1. Position cloth to collect fluid spillage.
    2. Lift out clutch master cylinder assembly.
    Pipe union and master cylinder removal (E105836)
  4. Remove the 2 remaining screws, remove pedal box top cover and discard gasket.
    5. Pedal box top cover screws (second) (E105833)
  1. Remove nut securing push rod to clutch pedal trunnion.
    2. Push rod nut removal (second) (E105832)
  2. Remove clutch pedal sensor and pipe union from master cylinder and discard sealing washers.
    1. Remove 2 bolts and remove clutch master cylinder from pedal bracket.
    Clutch pedal sensor and pipe union removal (second) (E105834)

Installation

  1. Check seal on pedal box at points indicated and seal with RTV if necessary.
    2. Pedal box seal check (second) (E107376)
  1. Install new lock nuts to master cylinder.
    2. New lock nuts installation (second) (E107377)
  2. Clean sensor and pipe union.
    1. Install new gasket.
    2. Position master cylinder to pedal bracket and align push rod to pedal trunnion.
    3. Install bolts and nuts and secure master cylinder to pedal bracket.
    4. Install clutch pedal sensor and pipe to master cylinder using new sealing washers.
    Sensor and pipe union installation (second) (E105834)
  3. Install clutch master cylinder and mounting bracket.
    1. Clean clutch pipe union.
    2. Align pipe and tighten union.
    Clutch master cylinder and mounting bracket installation (second) (E105836)
  1. Connect multiplug to clutch pedal sensor.
    2. Clutch pedal sensor multiplug connection (second) (E105835)
  2. Intsall the 6 bolts securing clutch pedal bracket to body.
    3. Clutch pedal bracket bolts tightening (E105828)
  3. Install clutch pedal rubber.
    4. Clutch pedal rubber installation (second) (E105831)
  4. Position closing panel and tighten screws to lower 'A' pillar.
    5. Closing panel positioning (second) (E105829)
  1. Install the 2 stoplamp switches.
    For additional information, refer to Stoplamp Switch (70.35.42)
  2. Install and lightly tighten nut securing push rod to clutch pedal trunnion.
    3. Push rod nut tightening (third) (E105832)
  3. Check distance from lower edge of clutch pedal to down position. Correct measurement is 135 mm (5.31 in).
    4. Clutch pedal travel measurement (second) (E107371)
  4. Adjust master cylinder push rod lock nuts and nylon nut untill 135mm (5.31 in) is achieved.
    1. Tighten lock nuts.
    2. Tighten nylon nut securing push rod to clutch pedal trunnion.
    Master cylinder push rod adjustment (second) (E107372)
  1. Check pedal travel is to correct measurement.
    2. Pedal travel measurement (third) (E107371)
  2. Install a new gasket to cover plate and secure with the 2 center screws.
    3. Gasket and cover plate installation (second) (E105833)
  3. Install the multiplug mounting bracket.
    1. Install the brake pipe mounting bracket.
    Multiplug mounting bracket installation (E105830)
  4. Install the coolant expansion tank.
    1. Connect the coolant expansion tank return hose.
  5. Bleed the clutch hydraulic system.
    For additional information, refer to Clutch System Bleeding

Clutch Slave Cylinder (33.35.01)

Removal

  1. WARNING: Do not work on or under a vehicle supported only by a jack. Always support the vehicle on safety stands.

    Raise and support the vehicle.

  2. Disconnect the battery ground cable.
    For additional information, refer to Battery Disconnect and Connect
  3. Remove the transmission.
    For additional information, refer to Transmission (37.20.02.99)
  4. Disconnect the fluid pipe.
    • Position an absorbent cloth to collect any fluid spillage.
    • Remove the clip.
    Fluid pipe disconnection (E49711)
  5. Remove the clutch slave cylinder.
    • Remove the 3 bolts.
    Clutch slave cylinder removal (E49709)

Installation

  1. Install the clutch slave cylinder.
    • Tighten the bolts to 10 Nm (7 lb.ft).
  2. Connect the fluid pipe.
    • Install the clip.
  3. Install the transmission.

For additional information, refer to Transmission (37.20.02.99)

  1. Connect the battery ground cable.
    For additional information, refer to Battery Connect
